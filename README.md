# 万物的来路

这是一个给自己玩的科技树探索册。从易拉罐开始，把制造过程接到材料、化学、物理与数学；允许长出岔路，也允许留下还没挖到的地方。

直接用浏览器打开 `index.html` 就能玩。无需安装依赖或构建服务；全部图与内容保存在本地。

在线探索：[ssdfz.sh.cn/back-to-basics/](https://ssdfz.sh.cn/back-to-basics/)。GitHub Pages 从 `master` 分支根目录发布；推送后自动更新，`.nojekyll` 让静态文件直接发布。

## 怎么玩

- **沿着问题走**：点节点，看它需要什么、为什么成立，再继续往下。
- **看整棵树**：看到不同枝条如何共用同一个原理。点节点会突出直接关联。
- 左侧有四条精选路线，也可以搜一个术语直接跳进去。
- 右边有机制、公式、适用条件、数值例子与来源。电解与薄壁节点带有可调参数的小计算。
- “复制这个节点的追问”可以把当前好奇心带回聊天；它不会自行联网或生成未经核实的节点。

## 怎么让它长大

直接在聊天里说：**“接着挖冰晶石”**，或者 **“下一个东西：圆珠笔”**。让 Codex 阅读这里的内容，修改知识网，再刷新页面。

`kb.json` 是内容的唯一编辑入口。每个节点有稳定的 `id`，节点文字与公式独立于画图代码。新物件可以复用摩尔、电荷、自由能、应力、扩散等基础节点。

修改 `kb.json` 后，运行：

```powershell
node build.js
```

`knowledge.js` 是浏览器可直接读取的生成文件；不用手工编辑。`research/` 保存这次初始研究稿，最终采用并修正后的内容以 `kb.json` 为准。

## 几个内容约定

1. 箭头从正在追问的对象指向依赖或解释。实线表示**制造依赖**，虚线表示**原理解释**；这些线不是历史先后顺序。
2. 不把知识网强行画成一棵无交叉的树。回收是另一条材料来源路线；同一原理常支撑许多物件。
3. 每个公式标变量、单位与适用条件。示例中的自设参数明确标为教学估算；不可把理想薄壁应力直接当作真实罐的失效预测。
4. 合金和工艺写典型情况，不声称所有易拉罐相同。保留标准态、温度、年份和统计边界。
5. 科学节点附可点击的一手来源。公式推演与自设例子用来帮助理解，不是来源中的实测结果。
6. 越往下会碰到量子态、统计规律与守恒定律。本版只展开一部分解释；这些定律本身“为何如此”不是再添一个标签就解决的。

没有服务端、数据库、用户账户和测试框架。这是一册能继续生长的私人玩具。

## 公式怎么写

所有公式统一使用 LaTeX。`equations[].formula` 直接保存 TeX 源码，页面将它排成独立公式；正文里的公式用 `\( ... \)`，另起一行用 `\[ ... \]`。化学物种与反应式使用 `\ce{...}`。

JSON 中的反斜杠要写成两个，例如：

```json
{"formula":"\\sigma_\\theta=\\frac{\\Delta p\\,r}{t}","example":"半径取 \\(33\\,\\mathrm{mm}\\)。"}
```

页面使用 [KaTeX](https://katex.org/docs/browser.html) 与 mhchem；渲染脚本和字体都保存在 `vendor/katex/`，离线可用。公式较长时可以在公式区域内横向滚动。
